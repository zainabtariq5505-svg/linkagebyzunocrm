## 🆘 Quick Help

### "It doesn't work"
1. Check http://localhost:3000 is running
2. Try refreshing page (Ctrl+F5)
3. Check browser console (F12)
4. See COMPLETED.md → Troubleshooting

### "I want cloud backup"
1. Follow SUPABASE_SETUP.md
2. Takes about 10 minutes
3. No data loss - automatic migration

### "I want to deploy"
1. Follow DEPLOYMENT.md
2. Vercel recommended (easiest)
3. Free tier available

### "Where's my data?"
1. Data stored in browser localStorage
2. Check: F12 → Application → localStorage
3. Key: `linkage_crm_data`
