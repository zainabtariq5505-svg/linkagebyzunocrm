================================================================================
                               IF SOMETHING GOES WRONG
================================================================================

PROBLEM: "Could not sync from Supabase"
SOLUTION:
  • Check .env.local has credentials (it does ✓)
  • Make sure database tables are created
  • Check browser console (F12) for errors
  • Try refreshing page

PROBLEM: "Tables don't appear in Supabase"
SOLUTION:
  • Make sure you ran the SQL query
  • Check the query executed without errors
  • Refresh the Supabase page
  • Try running SQL again

PROBLEM: "Data not appearing in Supabase"
SOLUTION:
  • Add new creator/video (must be added AFTER tables created)
  • Check Supabase Table Editor
  • Open browser console (F12) - look for sync messages
  • Verify tables exist first

PROBLEM: "App won't start"
SOLUTION:
  • Make sure .env.local file exists (it does ✓)
  • Run: npm install
  • Clear cache: rm -r .next (or delete .next folder)
  • Restart: npm run dev
