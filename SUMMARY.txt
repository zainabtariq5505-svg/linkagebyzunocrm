================================================================================
                         TROUBLESHOOTING
================================================================================

PROBLEM: App not loading
SOLUTION: 
  • Check http://localhost:3000
  • Run: npm run dev
  • Check: npm install (if needed)

PROBLEM: Data disappeared
SOLUTION:
  • Check browser localStorage (F12 → Application)
  • Data key: linkage_crm_data
  • Try adding data again

PROBLEM: Supabase not working
SOLUTION:
  • Check .env.local credentials
  • Verify database tables created
  • Check console errors (F12)
  • See SUPABASE_SETUP.md

PROBLEM: Cursor still flickering
SOLUTION:
  • Refresh page (Ctrl+F5)
  • Clear cache: npm run build
  • Restart dev server

For more help, see COMPLETED.md → Troubleshooting section
