Your code is ready! Follow these steps to deploy to production.

================================================================================
                         STEP 1: CREATE GITHUB REPO
================================================================================

1. Go to: https://github.com/new
2. Fill in:
   - Repository name: linkage-crm
   - Description: Premium Admin CRM for Linkage by Zuno
   - Visibility: Private (recommended) or Public
3. Click: "Create repository"
4. Copy the commands shown on the next page

================================================================================
                      STEP 2: PUSH CODE TO GITHUB
================================================================================

Run these commands in your terminal:

  cd d:\web\linkage-crm

  git remote add origin https://github.com/YOUR_USERNAME/linkage-crm.git
  git branch -M main
  git push -u origin main

REPLACE "YOUR_USERNAME" with your actual GitHub username!

After running:
  ✓ Refresh GitHub page
  ✓ You should see all your files there

================================================================================
                       STEP 3: DEPLOY TO VERCEL
================================================================================

1. Go to: https://vercel.com
2. Sign in (or create free account)
3. Click: "+ New Project"
4. Click: "Import Git Repository"
5. Paste your GitHub URL:
   https://github.com/YOUR_USERNAME/linkage-crm
   OR select from list
6. Click: "Import"

================================================================================
                       TROUBLESHOOTING
================================================================================

Build Failed?
  → Check Vercel build logs
  → Look for TypeScript errors
  → Verify environment variables set

App shows blank page?
  → Open browser console (F12)
  → Check for errors
  → Verify Supabase tables created

Can't push to GitHub?
  → Verify repository created
  → Check GitHub username in URL
  → Make sure you're in right directory
